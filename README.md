# 🌌 3D 专属星空粒子视界 · 刘涵馨 (3D Particle Universe)

基于 **Three.js** 与 **GPU GLSL Shader** 构建的 3D 浪漫粒子交互系统。在统一的三维球面坐标系中，以超高清正脸写真为主体，通过全态粒子流光形变算法，在不同视角间实现「正脸照片 $\rightarrow$ 名字书法 $\rightarrow$ 3D爱心」的无缝流光重组。

---

## ✨ 核心亮点

1. **统一全态粒子流光形变 (Unified Particle Metamorphosis)**：
   - 场景由 520,000 颗高精微粒构成，彻底杜绝多模型交叉切割穿插。
   - **正面机位 (0°)**：粒子聚合还原「涵馨女神」高清写真，保留微弱立体浮雕与自然呼吸。
   - **旋转至 120°**：粒子如星河解构飞散，精准重组凝聚为流光书法大字「**刘涵馨**」与英文副标。
   - **旋转至 240°**：粒子化为星尘，聚合重塑为一颗具有“怦、怦”双拍心跳律动的 **3D 饱满立体爱心**。
   - **转回正面**：粒子星云回流，重现笑颜。

2. **数学级 Taubin 3D 隐式曲面实心爱心**：
   - 采用图形学高阶隐式方程：
     $$(x^2 + y^2 + 2.25 z^2 - 1)^3 - x^2 y^3 - 0.1125 z^2 y^3 \le 0$$
   - 彻底消除交错线条与莫尔纹，生成浑然天成、圆润饱满的 3D 红宝石心形。

3. **三维球面坐标系与电影级巡航**：
   - 支持上下左右 360° 全景自由漫游探索，顶部 HUD 实时显示当前球面方位角（$\theta$）与俯仰角（$\phi$）。
   - 底部提供 3 个轻奢毛玻璃按钮，支持一键镜头平滑飞掠巡礼。

4. **全面移动端适配**：
   - 针对手机触屏优化，支持单指滑动 360° 旋转、双指捏合缩放。
   - 配置 `touch-action: none` 防止移动端下拉刷新或弹性滚动干扰。

## 🛠️ 本地运行

```bash
# 1. 克隆或进入项目目录
cd 3d-particle-image

# 2. 安装依赖
npm install

# 3. 启动本地开发服务 (支持局域网手机访问)
npm run dev

# 4. 构建生产版本
npm run build
```

## 📱 访问方式

- **电脑端**：浏览器访问 `http://localhost:5173/`，鼠标拖拽旋转。
- **手机端**：确保与电脑在同一 Wi-Fi，手机浏览器输入终端显示的 `Network` 局域网地址。
